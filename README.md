# Julia Kantzer, portfolio

Personal portfolio site. Vite + React + TypeScript, Tailwind CSS v4 with CSS-variable design tokens, Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All copy lives in `src/content.ts`. Components never hard-code text. Anything marked `TODO` in that file still needs your input.

Design tokens (colors, fonts) live at the top of `src/index.css`.

## Build and deploy

```bash
npm run build   # output in dist/
```

Deployment instructions are added in phase 4.
